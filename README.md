# Media Asset Management Web Portal

## About
Media Asset Management Portal is a web-based application that allows users to upload, organize and manage digital media files such as photos and videos.  
Users can tag their files, search them easily and manage their content through a secure role-based system.

## Project Purpose
The main goal of the project is to transform scattered media files into a structured, searchable and manageable system.

## Features
- Drag and Drop media upload
- Media metadata management (title and tags)
- Search and filtering system
- Pagination for large media collections
- Image preview and video playback
- Role-based access control (RBAC)

## User Roles
### Standard User
- Can upload media
- Can edit or delete their own files
- Cannot access other users' media

### Admin
- Can view all uploaded media
- Can manage or remove inappropriate content
